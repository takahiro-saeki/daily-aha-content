# Daily Aha content

「きょうのへぇ / Daily Aha」向けの記事・日本語と英語の原稿・イラスト配信データです。

アプリ内で署名と内容ハッシュを検証して使用します。配信版はreleases、内容ごとのファイルはobjectsに保持します。

記事は独自に編集したもので、出典元の監修や公式翻訳ではありません。イラストはAI支援で制作したイメージです。出典と利用上の注記は各記事に記載しています。

素材の再配布条件やお問い合わせは[サポートページ](https://takahiro-saeki.github.io/daily-aha-support/)へお願いします。
